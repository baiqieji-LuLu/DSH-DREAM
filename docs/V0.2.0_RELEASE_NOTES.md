# DSH-DREAM v0.2.0 发版说明

## 主题：全息记忆（Holographic Memory）

陪伴型 AI 不应把日常闲聊视为噪声。v0.2.0 将每一轮完整对话无条件写入 RAG：

- `user_message`：用户完整原话
- `assistant_message`：AI 完整原话
- `system_fact`：如果 LLM 抽取到事实，则作为同回合高亮标签，与前两者共享 `timestamp_ms`

事实不再决定原话是否入库。检索时 `system_fact` 优先出现在 Prompt 前面，但同回合原话保留，形成可回访的关系记忆。

## 主要变更

- 新增工具 `memory_add_turn(user_msg, ai_msg, extracted_fact=None)`：一次调用写入 user、assistant 和可选 fact，三者共享一个 `timestamp_ms`。
- 旧 `memory_add` 从 DSH 工具 Schema 移除，仅保留 Python 兼容函数；`AGENT_GUIDE.md` 强制每轮回复后调用 `memory_add_turn`。
- `MemoryAgent._finish` 无条件双写 user/assistant。
- 维度不一致改为无损重嵌入：
  - 缓存旧 `documents` / `metadatas`
  - 删除旧集合
  - 用新 embedding 重新计算并批量写回
  - 保留原 ID、来源、时间戳、metadata
- `embedding_base_url` 默认改为空字符串；云端 provider 必须显式填写，避免误连 OpenAI。
- UI Placeholder 改为：
  `例如 https://api.deepseek.com/v1（请确认与您的 API Key 匹配）`
- 自动重建复选框文案改为：
  `维度不匹配时，尝试无损重嵌入旧数据（注：若使用云端 API 会产生 Token 消耗）`
- 未勾选时错误提示：
  `请手动清空数据库，或勾选自动重嵌入`
- `search_memory` 的 BM25 软提权 + latest-wins 保留同回合全部记录，并让 `system_fact` 在同 timestamp 中排在最前。

## 发版命令

当前工作区没有 `.git`，且系统未安装 `git`。请在装有 Git 的终端执行：

```powershell
cd G:\deepseek_ragproject_workspace

# 已有仓库则跳过 init / remote
git init -b main
git add .
git commit -m "feat: v0.2.0 holographic companion memory and lossless re-embedding"
git tag -a v0.2.0 -m "DSH-DREAM v0.2.0"
git remote add origin <你的仓库完整地址>
git push -u origin main
git push origin v0.2.0

# Git 源码归档
git archive --format=zip --output=dist/agent-memory-v0.2.0.zip v0.2.0
```

Python 构建建议在普通 PowerShell（非当前受限沙箱）执行：

```powershell
.venv\Scripts\python.exe -m build
```

插件 zip：

```powershell
Compress-Archive -Path dsh_plugin\* -DestinationPath dist\agent-memory-dsh-0.2.0.zip -Force
```
