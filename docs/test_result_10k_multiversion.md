## 6. 逻辑说明

每次写入 metadata 都记录严格递增的 `timestamp_ms`。`search_memory()` 先做 HNSW，
查询含“密码”时通过 Chroma `$contains` 取关键词候选；随后将包含相同实体或高度相似的
记录归为冲突组，按 `timestamp_ms` 降序并执行 latest-wins，只把最新版本放入 Prompt。
